SNS運用代行の見積もりを2〜3社から取ったものの、「項目名がバラバラで比べられない」「金額が安いところを選んでよいのか分からない」と止まってしまう担当者の方は少なくありません。見積もりは、そのまま並べても比較になりません。**同じ条件にそろえてから並べて**初めて、判断の材料になります。

この記事では、BtoB企業が運用代行の相見積もりを比較するための項目と、比較表のひな型、見積もりを依頼するときの伝え方を整理します。特定の会社の優劣を示すものではなく、自社で比較表を作るための手順です。

## 要点ボックス（共有用）

- 見積もりは、金額ではなく「含まれる範囲」をそろえてから比べる
- 比べる項目は、範囲・本数と頻度・契約期間・初期費用・権限・権利・確認フロー・報告の8つ
- 「月額 × 契約期間 + 初期費用」で総額を出すと、見かけの安さに惑わされにくい
- 空欄があれば、推測せず各社に質問して埋める
- 比較表は、稟議の添付資料としてそのまま使える

## なぜ見積もりをそのまま比べてはいけないのか

運用代行の見積書は、会社ごとに書き方が違います。「月額固定」とだけ書いてあるもの、作業ごとに分けて書いてあるもの、基本料金とオプションに分けているもの。同じ「月額10万円」でも、含まれている内容が違えば、価格の意味は変わります。

たとえば、フォローズの料金ページでも説明しているように、投稿の作成とスケジューリングだけを代行する安価なサービスは、「何のために・誰に向けて発信するか」という戦略設計が含まれないケースが一般的です。投稿は続いても、問い合わせや商談への貢献が見えにくくなることがあります。反対に、戦略設計や分析まで含む場合は、金額が上がります。この2つを月額だけで比べても、安い・高いの判断はできません。

そのため、比較の前に**同じ物差しにそろえる作業**が必要です。その物差しが、次の8項目です。

## 比較する8項目

### 1. 月額に含まれる業務の範囲

最初に確認するのは、月額に何が含まれているかです。次の業務ごとに、「含まれる」「オプション」「含まれない」を書き分けます。

- 戦略設計（ターゲット、KPI、訴求ポイントの整理）
- テーマ・企画の設計
- 取材・ヒアリング
- 記事の執筆、投稿文の作成
- 投稿作業、スケジュール管理
- 分析と改善提案
- 月次のレポート

フォローズのサービス内容では、note運用代行は企画設計・記事執筆・タイトルと見出しの最適化・スケジュール管理・分析・月次の簡易レポートを、Threads運用代行はアカウント方針とターゲット設計・投稿テーマとフックの設計・投稿文の作成・スケジュール管理・反応の分析と改善提案・月次の簡易レポートを提供内容としています。このように、業務を分解して書き出すと、他社と比較しやすくなります。

### 2. 本数・文字数・頻度

次に、アウトプットの量です。note であれば月に何本、1本あたり何文字程度か。Threads であれば週に何投稿か。ここが書かれていない見積書は、比較できません。「月4本」と書かれていても、1本が1,000字なのか5,000字なのかで、工数は大きく違います。

見積もりを依頼するときは、本数と文字数の希望を自社から先に示すと、各社が同じ前提で見積もれます。フォローズの料金は、発信媒体の数、投稿頻度、記事の文字数などによって変動します。

### 3. 契約期間と解約条件

最低契約期間、更新方法、途中解約の可否と条件を確認します。フォローズでは、最低契約期間を原則3か月を目安にご案内しており、詳細な条件はご相談に応じて検討します。他社の見積もりでは、6か月や12か月の契約、自動更新、解約通知の期限が条件になっている場合があります。詳しい確認の仕方は、<a href="/blog/sns-agency-minimum-contract-initial-cost/">最低契約期間と初期費用</a>と<a href="/blog/sns-agency-contract-checklist/">契約書チェックリスト</a>で解説しています。

### 4. 初期費用

初期費用の有無と、その内訳です。アカウント設計、プロフィール作成、初回の戦略設計、キックオフの打ち合わせなど、何が初期費用になっているのかを確認します。月額に含まれている会社と、別に請求する会社があるため、必ず総額で比べます。

### 5. アカウントの権限

誰のアカウントで運用するのか、ログイン情報や管理権限を誰が持つのかを確認します。自社のアカウントを使う場合は、権限を自社に残せるかが重要です。契約終了時にアカウントが使えなくなる形は、リスクになります。乗り換えや内製化の際に問題になりやすい点は、<a href="/blog/sns-agency-switching-handover/">切り替え・乗り換え手順</a>で整理しています。

### 6. 制作物の権利

記事や投稿文の著作権が、契約終了後に誰に帰属するのか、自社が自由に転載・改変できるのかを確認します。権利の扱いが書かれていない場合は、書面で確認してください。著作権の基本については、文化庁の<a href="https://www.bunka.go.jp/seisaku/chosakuken/" target="_blank" rel="noopener">著作権に関するページ</a>が参考になります。

### 7. 確認フローと修正対応

公開前の確認の流れと、修正の回数や期間を確認します。BtoB 企業では、社内の確認者が複数いて、確認に時間がかかるケースが多くあります。修正が何回まで無料か、確認期限を過ぎたときの扱いはどうなるのか、見積書に書かれていない場合は質問しておきます。フォローズでは、すべての投稿を公開前に必ずご確認いただき、承認をいただいたうえで公開します。

### 8. 報告と分析の内容

月次の報告の形式、見る指標、改善提案の有無を確認します。数値だけを報告する会社もあれば、次の企画への反映まで含める会社もあります。指標の考え方は<a href="/blog/sns-kpi-guide/">BtoB企業のSNS運用で追うべきKPI</a>で解説しています。

## 比較表のひな型

上の8項目を、次のような表にまとめます。見積書の内容を書き写し、不明な点は空欄のまま残して、各社に質問します。

| 項目 | A社 | B社 | C社 |
|---|---|---|---|
| 月額（税抜） | | | |
| 初期費用 | | | |
| 最低契約期間 | | | |
| 総額（月額×期間＋初期費用） | | | |
| 戦略設計 | あり／なし／オプション | | |
| 取材・ヒアリング | | | |
| 執筆の本数・文字数 | | | |
| 分析・レポート | | | |
| アカウント権限 | 自社／会社 | | |
| 制作物の権利 | | | |
| 修正回数・確認期限 | | | |
| 解約条件 | | | |

空欄は「ない」という意味ではなく、「未確認」という意味です。推測で埋めずに、必ず質問して確認してください。

## 総額の出し方

比較表の中で最も役に立つのが、総額の行です。計算式は単純です。

**総額 ＝ 月額 × 最低契約期間 ＋ 初期費用 ＋ 必要なオプション費用**

たとえば、月額が安くても最低契約期間が長く、初期費用がかかる見積もりは、総額で見ると差が小さくなることがあります。逆に、月額が高くても、含まれる範囲が広く、期間の縛りが短ければ、総額で見たときに合理的な場合もあります。ここで挙げた数字はあくまで計算の例ではなく、各社の見積もりに自社で当てはめるための式です。

また、総額だけでなく、「その期間で何が手元に残るか」も確認してください。記事という資産が残るのか、投稿だけが残るのか、分析資料が残るのかで、価値は変わります。

## 見積もりを依頼するときの伝え方

比較を楽にする最大のコツは、**各社に同じ依頼文を送る**ことです。依頼文には、次の内容を入れます。

1. 自社の事業内容と、発信の目的
2. 希望する媒体（note、Threads、または両方）
3. 希望する頻度と本数
4. 希望する契約期間と開始時期
5. 社内の体制（担当者の人数、確認者）
6. 確認したい項目（権限、権利、解約条件、修正対応）

これを同じ文面で依頼すれば、返ってくる見積書の前提がそろいます。依頼文に答えられない項目（頻度や本数など）がある場合は、「提案を希望する」と書き、各社の提案内容を比較する形にします。

## 見積書を受け取ったあとに確認する質問例

比較表の空欄を埋めるときは、次のような質問をそのまま使えます。回答は、メールなど記録に残る形でもらっておくと、あとで確認できます。

- 月額に含まれる業務と、オプションになる業務を、一覧で教えてください
- 記事1本あたりの文字数の目安と、月の本数は何本ですか
- 最低契約期間と、期間内に解約する場合の条件を教えてください
- 初期費用の内訳を教えてください
- アカウントのログイン情報や管理権限は、契約中・契約終了後に誰が持ちますか
- 制作物の著作権は、契約終了後にどちらに帰属しますか
- 修正は何回まで対応でき、確認の期限を過ぎた場合はどうなりますか
- 月次の報告は、どの指標を、どの形式で受け取れますか

質問に対する答え方も、判断材料になります。具体的に答えられる会社は、運用の中身が整理されていると考えられます。曖昧な回答が続く場合は、契約前に書面で確認してください。口頭での説明だけで進めると、運用が始まってから「聞いていた内容と違う」という食い違いが起きやすくなります。

相見積もりの回答期限も、あらかじめ決めておきます。「〇月〇日までに見積書と質問への回答をください」と伝えておけば、比較のスケジュールが崩れません。回答までの早さや、期限への対応も、運用が始まってからのやり取りを想像する材料になります。

## 比較表を使った選び方の考え方

比較表ができたら、次の順に絞り込みます。

**1. 必須条件で足切りする。** 「アカウント権限を自社に残せる」「公開前に確認できる」など、譲れない条件を満たしていない会社を外します。

**2. 範囲と総額を並べる。** 残った会社を、含まれる範囲と総額で比べます。範囲が同じなら総額で、総額が同じなら範囲で判断します。

**3. 対応の質を見る。** 質問への回答の早さ、説明の分かりやすさ、こちらの課題への理解は、金額に表れない比較ポイントです。無料相談や打ち合わせの場で確認します。

**4. 運用の相性を見る。** 自社の業種への理解や、確認フローとの相性は、長く運用するうえで重要です。業種別の注意点は、<a href="/blog/manufacturing-note-threads-agency/">製造業</a>と<a href="/blog/professional-services-note-threads-agency/">士業・コンサル</a>の記事でも整理しています。

## 比較で見落としやすい5つの注意点

**「実績」の表記を鵜呑みにしない。** 実績の数字や事例が載っていても、条件が自社と同じとは限りません。数字の出典や、どの範囲の成果なのかを確認します。

**「バズ」を売りにしているかを見る。** BtoB の発信では、拡散よりも、見込み顧客や取引先に届くことが重要です。バズを前面に出す提案は、自社の目的と合うかを検討してください。

**成果の保証に注意する。** 発信の成果は、媒体や目標、運用期間によって変わります。短期間での成果を断定する提案には、根拠を確認してください。フォローズでは、3〜6か月ほどの継続運用で手応えが見え始めるケースが多いと案内していますが、即効性を保証するものではありません。

**成果報酬型の条件を確認する。** 成果報酬型は、固定費が低く見えても、成果の定義や上限、最低保証がどうなっているかで総額が変わります。詳しくは<a href="/blog/sns-agency-performance-based/">成果報酬型のSNS運用代行は得？</a>で整理しています。

**ステルスマーケティングの扱い。** 広告や宣伝に当たる投稿の扱いについて、会社がどのような方針を持っているかを確認します。消費者庁が公表している<a href="https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/" target="_blank" rel="noopener">ステルスマーケティング規制に関するページ</a>で、基本的な考え方を確認できます。

## 稟議に使う場合のまとめ方

社内で稟議が必要な場合、比較表は添付資料としてそのまま使えます。説明の順番は、①目的、②比較した会社と条件、③選定理由、④費用と期間、⑤評価する指標と見直しの時期、とすると、決裁者が判断しやすくなります。稟議書の構成は<a href="/blog/sns-agency-ringi-approval/">SNS運用代行の稟議書の書き方</a>で詳しく解説しています。

## まとめ：比較表は「そろえる」作業で決まる

相見積もりの比較は、金額を並べる作業ではなく、条件をそろえる作業です。含まれる範囲、本数と頻度、契約期間、初期費用、権限、権利、確認フロー、報告の8項目に書き写し、空欄は質問で埋め、総額で並べる。この順番で進めれば、月額の安さに惑わされず判断できます。
